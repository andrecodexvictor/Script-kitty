# .dotstack

## Stack
- Frontend and CLI: TypeScript.
- Agent runtime and validation plugins: Python.
- Policy core and high-trust utilities: Rust.

## Runtime
- Docker-first.
- VM profile for lab mode.
- Self-hosted deployment.

## Dependencies
- MCP gateway.
- Audit log storage.
- Policy engine.
- Plugin loader.

## Constraints
- Safe-by-default execution.
- Isolated high-risk modules.
- Clear separation between orchestration and execution.
